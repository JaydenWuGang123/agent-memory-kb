# 三层隔离与四级漏斗架构说明

本知识库采用**「三层敏感度隔离 + 四级知识提炼漏斗」**架构，把多端 AI 对话与本地 Git 仓库整合成可检索、可自检、可容灾的个人外脑。

## 三层隔离边界

1. **Tier 1（本机运行时与凭证层）**：密钥、Token、Keychain 口令仅保存在系统密钥链或受控环境变量，严禁入库。
2. **Tier 2（本地私有知识库）**：Markdown + Git + 本地/iCloud 加密 `git bundle` + 私有 Git 远端 + OneDrive 端到端加密同步。
3. **Tier 3（公开脱敏共享层）**：`共享摘录/` 经 `kb_doctor.py` 脱敏门禁校验后，方可人工确认发布至公开仓库。

## 日常运维命令

```bash
# 全量刷新（导出、索引、错题扫描、体检、提交与备份）
python3 _同步/build_kb_index.py --output-root .

# 混合语义 + FTS5 检索
python3 _同步/kb_search.py -q "关键词或自然语言问题" --mode hybrid --limit 10

# 健康巡检与灾备恢复演练
python3 _同步/kb_doctor.py --root .
python3 _同步/kb_restore_verify.py --root . --check-icloud --json
```
